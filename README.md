# Fratelli Kanata

Rebuild of [fratellikanata.ca](https://www.fratellikanata.ca/) — Kanata only.

499 Terry Fox Drive, Kanata, ON K2T 1H7. Tables by phone: (613) 592-0225. Parties of 10+: events@fratelli-kanata.ca.

This preview does not take reservations. Takeout is phone-only. `fratelli.ca` is Fratelli Westboro (275 Richmond Road) — not this room.

```bash
npm install
npm run dev -- --port 3640
```
